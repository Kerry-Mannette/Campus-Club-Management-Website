# Campus-Club-Management-Website

A simple, responsive website for managing campus clubs and activities, built with HTML, CSS, and JavaScript.

## Features
- Club listings and descriptions
- Event pages and schedules
- Contact and membership information
- Responsive layout for desktop and mobile

## Getting Started
1. Clone the repository:
   ```
   git clone https://github.com/Kerry-Mannette/Campus-Club-Management-Website.git
   ```
2. Open `index.html` in your browser to view the site locally.
3. Optionally serve the folder with a static file server (e.g., `npx http-server` or Live Server extension).

## Project Structure
- `index.html` — main landing page
- `css/` — stylesheets
- `js/` — JavaScript files
- `images/` — project images and assets
- `pages/` — additional HTML pages (events, clubs, contact, etc.)

## Technologies
- HTML5
- CSS3 (responsive design)
- Vanilla JavaScript
